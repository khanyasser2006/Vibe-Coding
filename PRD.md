# Product Requirements Document (PRD): Ciné Haute Glacerie

## Overview
Luxury artisanal ice creamery web experience combining cinematic 60fps video canvas scroll with refined editorial design and interactive ordering workflows.

## Core Milestones
- [x] **Milestone 1: Visual Design & Token Compliance**
  - Implement strict palette: Peach (`#FEC5A8`), Tangerine (`#F4784E`), Terracotta Dark (`#38140B`).
  - Typography system: Playfair Display + Plus Jakarta Sans.
- [x] **Milestone 2: High Performance Canvas Scroll**
  - Optical-flow interpolated frame sequence with off-thread bitmap decoding.
  - Zero-jitter integer rendering and independent rAF loop.
- [x] **Milestone 3: Tasting Flight & Boutique Suite**
  - Interactive custom flight drawer, flavor cards, boutique locations.
- [ ] **Milestone 4: Autonomous Playwright & Quality Suite**
  - End-to-end canvas animation and navigation verification.
