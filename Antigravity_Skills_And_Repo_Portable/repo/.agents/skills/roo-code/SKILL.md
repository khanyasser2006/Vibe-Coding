# Roo Code Autonomous Modes & Workflows

This skill brings Roo Code's multi-mode architecture and specialized agent workflows into Antigravity globally.

## Core Modes
- **Architect Mode**: High-level system architecture, design specifications, and migrations.
- **Code Mode**: Everyday coding, implementation, refactoring, and test writing.
- **Ask Mode**: Read-only codebase exploration, architecture Q&A, and documentation.
- **Debug Mode**: Systematic debugging, root-cause analysis, and regression testing.
- **Issue Fixer Mode**: End-to-end GitHub issue resolution.
- **PR Fixer Mode**: Addressing pull request review comments and CI failure logs.
- **Merge Resolver Mode**: Intelligent git merge conflict resolution.
